# 面霸竞技场后端 - 安装与运行指南
# 专为初学者编写，一步一步跟着做

## 第一步：安装 Python 3.10

你目前有 Python 3.14，但 DeepFace 不支持这么新的版本。
需要额外安装 Python 3.10（两个版本可以共存，不会冲突）。

1. 打开浏览器，访问：https://www.python.org/downloads/release/python-31011/
2. 找到页面最底部，点击 "Windows installer (64-bit)" 下载
3. 运行安装包，安装时注意：
   - ✅ 勾选 "Add Python 3.10 to PATH"（重要！）
   - 点击 "Install Now"
4. 安装完成后，打开"命令提示符"（按 Win+R，输入 cmd，回车）
5. 输入以下命令确认安装成功：
   py -3.10 --version
   应该显示：Python 3.10.x


## 第二步：下载后端代码

把本文件夹（mianba_backend）里的所有文件放到你电脑上的某个位置。
例如放到：C:\Users\你的用户名\Desktop\mianba_backend\


## 第三步：获取 DeepSeek API Key

1. 打开浏览器，访问：https://platform.deepseek.com
2. 注册账号（可以用邮箱注册）
3. 登录后，点击左边菜单的 "API Keys"
4. 点击 "创建 API Key"，复制那串以 "sk-" 开头的密钥
5. 打开 app.py，找到这一行：
   DEEPSEEK_API_KEY = "sk-你的DeepSeek密钥填在这里"
   把引号里的内容替换成你的真实密钥，保存文件


## 第四步：安装依赖库（只需要做一次）

1. 打开"命令提示符"（Win+R → cmd → 回车）
2. 进入你的项目文件夹（把路径换成你自己的路径）：
   cd C:\Users\你的用户名\Desktop\mianba_backend

3. 创建虚拟环境（隔离环境，避免和其他项目冲突）：
   py -3.10 -m venv venv

4. 激活虚拟环境：
   venv\Scripts\activate
   （激活后命令行前面会出现 (venv) 字样）

5. 安装所有依赖（大约需要5-10分钟，DeepFace比较大）：
   pip install -r requirements.txt

6. 等待安装完成，看到 "Successfully installed..." 就说明成功了


## 第五步：运行后端

每次使用时都需要运行以下步骤：

1. 打开命令提示符，进入项目文件夹：
   cd C:\Users\你的用户名\Desktop\mianba_backend

2. 激活虚拟环境：
   venv\Scripts\activate

3. 启动后端服务：
   python app.py

4. 看到以下输出说明启动成功：
   ==================================================
   面霸竞技场后端启动中...
   访问 http://localhost:5000/health 测试是否正常
   ==================================================
   * Running on http://0.0.0.0:5000

5. 打开浏览器，访问 http://localhost:5000/health
   看到 {"message": "面霸竞技场后端运行正常 ✓", "status": "ok"} 就成功了！

⚠️ 注意：后端运行时那个命令提示符窗口不能关闭，关了后端就停了。


## 第六步：测试所有接口

保持后端运行，再开一个新的命令提示符窗口：

cd C:\Users\你的用户名\Desktop\mianba_backend
venv\Scripts\activate
python test.py

全部显示 ✓ 就说明一切正常！


## 第七步：把前端连接到后端

把 api_client.js 文件复制到你的前端项目的 src/ 文件夹里。

在你原来调用 aiAnalysis.js 的地方，改成从 api_client.js 导入：

// 原来的写法（删掉）
import { analyzeAnswer } from './aiAnalysis'

// 改成这样
import { scoreAnswer, startFaceAnalysis, stopFaceAnalysis, generateReport } from './api_client'

具体用法示例：
// 评分一个回答
const result = await scoreAnswer("请介绍你自己", userAnswer, "产品")
console.log(result.total_score)      // 总分
console.log(result.interviewer_comment) // 面试官评价

// 开始面部分析（传入 video 元素）
startFaceAnalysis(videoRef.current, (result) => {
  console.log(result.emotion_cn)  // 当前表情
})

// 面试结束，停止面部分析
const faceSummary = stopFaceAnalysis()

// 生成综合报告
const report = await generateReport("产品", qaList, faceSummary, 10)
console.log(report.overall_score)


## 常见问题

Q: 安装 deepface 的时候报错？
A: 试试：pip install deepface --no-cache-dir

Q: 运行时提示 "Port 5000 already in use"？
A: 打开任务管理器，找到占用5000端口的程序关掉，或者把 app.py 最后一行的 port=5000 改成 port=5001

Q: 前端请求后端时报 "CORS error"？
A: 后端已经加了 CORS 配置，如果还是报错，检查前端的 BACKEND_URL 是否正确

Q: DeepFace 分析很慢？
A: 第一次运行会下载模型文件（约500MB），之后就快了。确保网络正常。
